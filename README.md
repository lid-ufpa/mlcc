# 📦 Machine Learning Crash Course (MLCC)

Este repositório reúne os materiais do curso *Machine Learning Crash Course: Hands-on with Python*.  

Inclui as apresentações em PDF e notebooks interativos (`.ipynb`) organizados por aula.

# ⚙️ Configuração do Ambiente

Para utilizar os notebooks `.ipynb` e acessar os materiais do curso, siga os passos abaixo:

### 1. Crie um ambiente virtual

Você pode escolher entre `Poetry` ou `venv + pip`:

- **Com Poetry** (fortemente recomendado):

```
poetry install
```

- **Com venv e pip**:

```
python -m venv env

source env/bin/activate

pip install -r requirements.txt
```

### 2. Acesse os materiais

Os notebooks (`.ipynb`) e slides (`.pptx`) estão organizados nas pastas `aula1`, `aula2`, ..., conforme o conteúdo do curso.
