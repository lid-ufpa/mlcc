# MLCC
Conteúdo do Machine Learning Crash Course do LID-UFPA

# Configurações

Para utilizar os documentos ipynb, siga os seguintes passos.

1. Crie um ambiente virtual para o projeto.

- Usando Poetry.

```poetry install```

- Usando pip.

```python -m venv env```

```source activate env```

```pip install -r requirements.txt```

2. Utilize a receita `all` do Makefile para criar os diretórios e baixar os arquivos necessários:

```make all```

3. Acesse as aulas nos diretórios `aulaX`, contendo os documentos em formato .ipynb e os slides de aulas em formato .pptx.
